# MFile_Manager Android APK

This project wraps `filemanager_m3_expressive.html` in a native Android WebView.

## Build APK

Open this `android` folder in Android Studio, then choose:

`Build > Build Bundle(s) / APK(s) > Build APK(s)`

The APK will be created at:

`android/app/build/outputs/apk/debug/app-debug.apk`
