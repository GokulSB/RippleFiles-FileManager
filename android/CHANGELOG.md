# Changelog

## [1.0.1] - 2026-07-07

### Added
- **Icon Shape Customization**: 9 new custom icon shape options for folders and files. Added a new section in the Display and Theme settings.
- **Auto Icon Shape Mode**: When "Auto" is selected, the app randomly changes the icon shape on every launch for a fresh look.
- **Persistent Settings**: Icon shape, Theme Mode (Light/Dark/System), Theme Color (Hue), and Dynamic System Theme preferences are now saved and persist across app restarts.
- **Batch Rename Enhancements**: 
  - Added a live preview inside the Base Name text box, showing the formatted filename as you change padding, start number, and prefix/suffix toggle.
  - Underscores (`_`) are now automatically inserted after the prefix or before the suffix.
- **File Viewer Support**: The built-in text viewer now supports opening `.json`, `.xml`, `.csv`, `.md`, and `.log` files seamlessly without throwing a "No viewer available" error.

### Changed
- **Pin Icon UI Redesign**: 
  - Moved the Pin icon to the very top-left corner of the outlined file/folder container in both Grid and List views.
  - Removed the circular background container for a cleaner look.
  - Increased the pin icon size to 28dp.
  - Tilted the pin icon 45 degrees to the right for a more dynamic appearance.
